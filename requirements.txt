# TextKit — 8 text tools for writers, bloggers and sellers

**Convert case, count words, dedup lines, generate slugs, sort, trim and find/replace — one command each. No coding needed.**

## Free (3 scripts)

| Tool | What it does |
|------|-------------|
| **Convert text case** | upper, lower, title, sentence, snake, camel, kebab, slug |
| **Word count** | lines, words, characters, paragraphs, top words |
| **Remove duplicate lines** | dedup lines, keep first occurrence |

## Quick start

```bash
# 1. Install Python (free): https://python.org
# 2. Open a terminal in the scripts/ folder

python case_convert.py essay.txt --to title
python word_count.py essay.txt --top 10
python remove_duplicate_lines.py essay.txt --out clean.txt
```

Requirements: **Python 3.8+**. No extra dependencies.
